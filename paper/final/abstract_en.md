# English Abstract

On-device small language models must address memory capacity and weight-delivery bandwidth within tight power and cost limits. This work evaluates an extensible candidate architecture in which a Kria K26 handles control and computation while an external Memory FPGA supplies weights through multiple memory channels. From the 7,837-node Gemma 3 1B graph, 183 projections per token are mapped to 802 dependency-aware output tiles and evaluated under four initial placements and three queue policies. On a synthetic skew workload, locality-aware work stealing reduces TileJob p95 by 19.13% against static placement. On Gemma-shaped tiles, however, the p95 effect ranges from +0.28% to −19.79% depending on initial placement, and the modeled K26-local baseline remains shorter than the external 6.4-GB/s candidate. External 8GB memory and work stealing are therefore conditional expansion mechanisms rather than requirements for Gemma 1B. The results are based on bounded RTL simulation and analytical models, not board measurements.

**Keywords:** on-device sLLM, Kria K26, Memory FPGA, multi-channel memory, work stealing, SpinalHDL
