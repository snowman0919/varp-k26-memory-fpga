# v11-final 변경 기록

- 외부 8GB의 용량 필수 가설을 기각하고 K26 로컬 우선 결정을 본문에 반영했다.
- Gemma 3 1B를 토큰당 802개 TileJob으로 변환하고 계층·토큰 의존성을 적용했다.
- 원격 데이터 이동을 링크 서비스 시간에 부과하고 네 초기 배치를 비교했다.
- 대표 실제 타일 세 개의 작업 수락→DMA→응답→논리 링크→MatVec 경로를 닫았다.
- 합성 편향 부하와 Gemma 배치 민감도를 분리해 조건부 효과로 해석했다.
- KiCad 자료를 전체 보드가 아닌 일반 경계 라우팅 참조 쿠폰으로 한정했다.
- 14장 한국어 발표, Manim 영상 4개, 발표자 노트와 89개 Q&A를 최종 동기화했다.
- GitHub Release 자산과 Git 추적 소스를 분리하고 통합 공개 인덱스를 추가했다.
