# Review 1 — 독창성과 가속기 공동설계

판정: **FAIL**

독립 검토자는 기존 원고를 “실제 Gemma 작업을 이용한 작업 훔치기 정책·검증 범위
감사 논문”으로 분류했다. K26–Memory FPGA는 아직 채택이 보류된 배경 후보이며,
저비용·저전력 온디바이스 가속기 구조 논문으로는 근거가 부족하다고 판단했다.

## Critical

1. Gemma 1B가 로컬 4GB에 들어가므로 외부 8GB의 필요성을 입증하지 못했다.
2. 메모리 응답→링크→MatVec 데이터 경로가 끊겨 있었다.
3. 합성·배치배선·보드 전력·전체 BOM이 없어 저비용·저전력을 주장할 수 없다.
4. KiCad 자료는 실제 FPGA·K26 커넥터가 없는 축소 라우팅 쿠폰이다.
5. 기여와 결과가 하드웨어 구조보다 S1/S2/S3 비교에 치우쳤다.

## 요구한 수정

- K26-local과 외부 메모리 후보를 동일 조건으로 비교한다.
- 작업→DMA→응답→링크→연산 경로를 논리 RTL에서 닫고 실제 타일 trace를 남긴다.
- K26와 Memory FPGA의 역할과 채택 임계값을 명확히 한다.
- Work Stealing을 시스템의 종속 정책으로 내린다.
- KiCad를 전체 보드가 아닌 제한된 인터페이스 라우팅 쿠폰으로 재분류한다.

이 검토는 읽기 전용 독립 에이전트가 수행했으며 원고를 수정하지 않았다.
