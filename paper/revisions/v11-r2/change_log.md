# v11-r2 변경 기록

- 원격 복사 비용을 분석 모델의 링크·메모리 서비스 시간에 포함했다.
- Gemma 투영을 802개 TileJob/토큰으로 변환하고 단계·토큰 의존성을 추가했다.
- 네 초기 배치와 K26-local/외부 메모리 민감도 비교를 추가했다.
- 합성 부하는 paired seed 중앙값으로 다시 계산했다.
- 실제 가중치 타일 세 개가 DMA 요청부터 MatVec 결과까지 통과하는 폐루프 논리
  RTL trace를 추가했다.
- 외부 8GB와 Work Stealing을 기본 해법이 아니라 조건부 후보로 재분류했다.
- 모든 논문 Figure의 최종 최소 글꼴 8pt와 페이지 배치를 자동 검증했다.
