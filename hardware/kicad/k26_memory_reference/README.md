# K26 / XC7K160T hierarchical conditional reference

> **NOT FOR FABRICATION — proposal_only**

This hierarchy records the Phase-A architectural boundaries: K26 SOM PL-GTH,
XC7K160T-2FFG676I package resources, four independent DDR3L x16 channels,
four full-duplex serial lanes, clock/reset/config, power, and JTAG.

It is intentionally not a complete electrical design. Exact FPGA balls,
MIG-generated placement, SI/PI, power sequencing and production DDR3L MPNs
remain unresolved gates.
