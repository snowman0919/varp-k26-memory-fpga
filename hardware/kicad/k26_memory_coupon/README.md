# K26 memory/interface validation coupon

> **NOT FOR FABRICATION — proposal_only**

This electrically connected KiCad 9 coupon accounts for one DDR3L x16
representative channel slice, a four-lane full-duplex K26 PL-GTH link bundle,
two K26 GTH reference-clock inputs, reset/config/JTAG, and a decoupling subset.

The XC7K160T and K26 are connector/bank boundaries. No XC7K160T FFG676 ball,
MIG placement, production stackup, impedance, or timing claim is made.
