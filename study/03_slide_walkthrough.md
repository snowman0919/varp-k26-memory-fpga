# 17장 슬라이드 순회

1. 표지에서 연구 질문을 계산·메모리 분리의 채택 조건으로 고정한다.
2. 문제·구조·실제 모델·채택 조건의 네 질문을 예고한다.
3. 1B가 4GB에 들어가 질문을 용량에서 공급 분리로 바꿨다.
4. K26은 계산·제어를, Memory FPGA는 다채널 가중치 공급을 맡는다.
5. 기존 접근과 달리 작업 배치와 데이터 위치를 하나의 설계 흐름으로 연결한다.
6. 실제 Gemma 가중치 세 타일의 16×4 INT8 MatVec RTL 산술 일치를 확인한다.
7. 정적 로컬 큐는 지역성을 지키지만 유휴 연산기를 만든다.
8. 지역성 인식 작업 재분배는 기다림 감소가 데이터 이동 비용보다 클 때만 동작한다.
9. 183개 투영을 의존성이 있는 802개 연산 타일로 나눈다.
10. 같은 대표 작업에서 정적 배정과 지역성 인식 재분배의 사건 구간을 비교한다.
11. 재분배 효과가 부하 불균형과 초기 데이터 배치에 조건부임을 보인다.
12. 줄어든 큐 대기와 늘어난 링크·메모리 비용의 비교 기준을 분리한다.
13. 시험한 민감도에서는 외부 메모리보다 K26 로컬 경로가 유리했음을 보인다.
14. KiCad 결과를 제작 보드가 아닌 참조 라우팅 쿠폰으로 제시한다.
15. 한계와 향후 탐구 방향을 K26 실측→물리 경로→SI/PI·전력·열 검증으로 정리한다.
16. 구조·효과 조건·현재 채택 판단을 세 문장으로 결론 낸다.
17. 질문과 토론 화면에서 멈추고 상세 답변은 발표자 참고 자료로만 준비한다.
