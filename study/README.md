# VARP v11 발표·논문 방어 스터디팩

이 자료는 수치를 외우기보다 왜 질문이 바뀌었고, 무엇을 만들었으며, 어떤
조건에서만 유효한지 설명하도록 돕는다.

## 30분 학습 순서

1. 한 장 요약과 개념 지도를 읽는다.
2. 슬라이드 순회의 14개 기억 문장을 소리 내어 말한다.
3. 예상 질문과 답변의 Q1–20과 적대적 질문을 답한다.
4. 모든 수치 앞에 분석 모델/RTL 시뮬레이션/직접 확인 중 하나를 붙인다.

## 답변 규칙

- Work Stealing을 주인공으로 만들지 말고 시스템 구조의 조건부 수단으로 설명한다.
- Gemma 1B는 K26 로컬 우선, 외부 8GB는 확장 후보라고 답한다.
- 폐루프 **논리** RTL과 미완성 GTH·MIG **물리** 경로를 구분한다.
- KiCad는 전체 보드가 아니라 참조 라우팅 쿠폰이라고 말한다.
