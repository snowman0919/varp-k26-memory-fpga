# 면접·심사 답변 스크립트

## 20초 소개

“K26이 연산하고 외부 Memory FPGA가 가중치를 공급하는 확장 후보 구조를 설계했습니다.
Gemma 실제 형상을 의존성 있는 TileJob으로 바꾸고, 데이터 이동 비용을 포함해
Work Stealing이 유효한 조건을 분석했습니다. Gemma 1B는 K26 로컬 우선이며,
외부 구조는 더 큰 모델과 실제 로컬 경합에서 다시 평가합니다.”
